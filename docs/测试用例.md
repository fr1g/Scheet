# Scheet 测试用例

> 依据 plan.md 的功能拆分整理，供每个里程碑验收时逐条勾选使用。
> **黑盒（BB）**=手工执行的功能验收用例；**白盒（WB）**=已落地的自动化单元测试（`cargo test`，在 src-tauri/ 下运行）。
> 涉及"当前时间"的用例（提醒链路）如无法等待真实时间点，可用"创建一个 2~3 分钟后的事务"替代。

## 已知限制（记录用）

- 周课表提醒不做离线补发：应用关闭期间到期的事件不补发（手动 reminders 表的提醒会补发）。
- 保存/编辑若恰好与某提醒的到期发生在同一秒内，该次提醒可能被时间窗机制跳过（防止误响的代价）。
- 系统通知（WinRT Toast 等）实现保留但默认停用，提醒推送统一走置顶弹窗（勿扰模式不受影响）。
